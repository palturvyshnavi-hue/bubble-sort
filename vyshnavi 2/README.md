# Bubble Sort Java

Bubble Sort is a sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order.

## Files

* `BubbleSort.java` - Bubble Sort program
* `BubbleSortTest.java` - Testbench
* `output.txt` - Test output

## Run

Compile:

```bash
javac BubbleSort.java BubbleSortTest.java
```

Run program:

```bash
java BubbleSort
```

Run testbench:

```bash
java BubbleSortTest
```

